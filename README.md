# Bering Sea Crab Vitality Metrics

**Project Leads:** Erin Fedewa, Cory Lescher

## Project Overview
* This project aims to assess the condition (i.e. shell condition, injuries) and vitality of crab bycatch in groundfish fisheries. Collections taken by the NOAA AFSC Observer Program and at-sea observers will provide the initial first step in developing bounds on mobile and fixed gear bycatch mortality rates applied in Bering Sea crab stock assessments.
